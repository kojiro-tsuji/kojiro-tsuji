- 🛠️ Web・モバイル・デスクトップのアプリを、企画からデザイン・公開まで1人で作っています
- ⏱️ 最近のテーマは **「時間の記録」**。計った時間をそのままカレンダーに残すアプリを作っています
- 🤖 AI エージェントのチーム（実装・レビュー役）と一緒に開発する仕組みを、自分で組んで使っています
